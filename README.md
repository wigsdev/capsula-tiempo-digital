# Capsula del Tiempo Digital

Pagina web construida con HTML5 y CSS3 que representa una capsula del tiempo digital donde una persona deja informacion sobre si misma para leerla en el futuro.

## Tecnologias

- HTML5 (semantico)
- CSS3 (Flexbox, Grid, Responsive Design)
- Google Fonts (Playfair Display, Inter)

## Restricciones

- Sin JavaScript
- Sin frameworks CSS

## Estructura del proyecto

```
capsula-tiempo-digital/
├── index.html
├── css/styles.css
├── img/
├── audio/
└── video/
```
